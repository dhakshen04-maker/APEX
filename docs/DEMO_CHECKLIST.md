# APEX Professor Demo Checklist

## 1. Open the desktop app

- Dashboard loads.
- Class count and active-student count are visible.
- No fake student roster is shown.

## 2. Create a class

- Open **Students**.
- Create a department and section, for example `CSE` + `A`.
- Select the new class.

## 3. QR enrollment

- Select **QR enrollment**.
- Generate a fresh QR session.
- Scan it from a phone.
- Confirm the phone opens the APEX enrollment page.
- Enter a real/demo student name and roll number.
- Submit.
- The phone displays the student's QR.
- In APEX, use **Scan student QR**.
- Confirm the student is added to the selected class roster.

## 4. QR attendance

- Open **Attendance**.
- Select the class.
- Start a QR attendance session.
- Open the student check-in page from the attendance QR.
- Complete the check-in flow.
- Scan the student check-in QR in APEX.
- Confirm the attendance record changes.

## 5. Review

- Show the attendance percentage.
- Filter below the 75% threshold.
- Open the spreadsheet/report workspace.
- Show the class roster and messaging workflow.

## Demo safety

Use only test/demo student information. Do not put real student personal data, passwords, API keys or institutional credentials into a public GitHub repository or GitHub Pages URL.
